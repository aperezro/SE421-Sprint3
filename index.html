Why this matters for security

An algorithmic-complexity denial of service can happen when a crafted input forces a program to perform far more work than ordinary inputs. For example, a function that branches into two recursive calls at every level grows approximately as 2ⁿ. Increase the input size above and compare its growth with linear and logarithmic algorithms.

Try this: Set n to 10, select branching recursion, then increase n to 20. How many times more operations are needed? (Answer: 1,024×.)

Safety: This is a mathematical simulation. It does not run expensive recursion, send network requests, or attack any service.
